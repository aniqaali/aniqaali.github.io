CardIO

Cardio is a flashcard generator website designed to make studying for students faster and more efficient.

View Project

Tech Stack

Angular TypeScript FastAPI PostgreSQL Python

The Problem

Many college and high school students struggle to extract important and key points from large readings or lectures while also needing to manually create flashcards as a study tool. Cardio was designed to address these challenges and improve the studying experience.

Brainstorming

I worked with 3 other teammates to brainstorm ideas for the flashcard generator. We developed 2 user stories and generated wireframes for initial layout of the website. We wanted a more fun yet sleek design for the UI.

Final Solution & Development

The final solution incorporates the 2 user stories split up into 2 sprints split between the teammates. We tracked our progress using the issues and project board tracker in GitHub. Our frontend was developed using TypeScript and Angular while the databases and backend was developed using PostgreSQL, Python, and FastAPI. The main feature is that users can upload a pdf or pptx, generate a prompt to give to the built in AI, and have 10 flashcards generated based on the prompt and uploaded pdf and pptx. Additional features include viewing the entire deck of cards at once, saving sets of cards, naming titles of sets, and toggling between light and dark mode.

Result of Project

Cardio became a functional app prototype that combined user-centered design with API-based development. Through this project, I strengthened my understanding of how servers and clients communicate and how APIs and databases are used to build modern web applications.

Future Recommendations

Future improvements would include performance tracking of the flashcard sets generated. This would include tracking which cards were correctly or incorrectly answered and how performance has improved or gotten worse over time.
