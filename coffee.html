Evolution of Coffeehouses and Trends in Coffee Consumption

This project highlights the reasons that coffee shops have been used throughout history globally as well as how the architecture has evolved.

View Project

Tech Stack

HTML CSS JavaScript

Inspiration

An avid coffee connoisseur and a frequenter of coffee shops, I was interested in seeing how coffee shops have evolved architecturally and in terms of reasons for usage throughout history globally.

Brainstorming

I wanted to replicate the feeling of being inside a coffee shop, so i chose brown and beige as my leading colors. Each page background features a warm, inviting scene that mimics the ambiance of a traditional coffeehouse, reflecting the time period highlighted on that page. I wanted the design to tell the story of coffeehouses.

Development

Utilizing HTML and JavaScript, I created an interactive storytelling website. Each page has dropdown cards informing users of different features of the coffeehouse during that time period. CSS was used for styling.

Result of Project

This project allowed me to hone in more on my JavaScript skills. I was also able to conduct research to drive my styling and content decisions.

Future Recommendations

Future improvements could include a storybook type interactive storytelling feature, audio, and moving elements.
