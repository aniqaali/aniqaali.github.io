Popular American Housing Through the Years

This project highlights the evolution of housing styles in the United States throughout the centuries.

View Project

Tech Stack

HTML CSS JavaScript

Inspiration

Continuing my passion for diving into history, I was personally interested in how housing has changed through the different centuries of American history.

Brainstorming

I wanted this website to look more modern and almost have a house listing website aesthetic. I also wanted to incorporate interactive features. I decided to go with a mild teal style color, whites, browns, and blacks for the fonts and other designs.

>

Development

Utilizing HTML and JavaScript, the website includes interactive features such as flipcards to see the different features of each housing style as well as a 3D video tour link. CSS was used for styling and layout of the website. Parallax screens are included on the home page. The website is also designed to be responsive across different devices. Some of the icons were generated using ChatGPT.

Result of Project

The housing website became a functional prototype that combined user-centered design with modern web development techniques. Through this project, I strengthened my skills in HTML, CSS, and JavaScript, while engaging in a project of personal interest.

Future Recommendations

Future improvements could include a more sleek look to improve the modern aesthetic and interactives showing where these types of houses are spread across the United States.
